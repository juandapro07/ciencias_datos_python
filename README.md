# Ciencia de Datos con Python - Semana 1

## Propósito
Preparar el ambiente de trabajo, comprender el ciclo de vida del dato y evaluar el valor de la información para apoyar la toma de decisiones informadas.

## Estructura del Proyecto
- `data/raw`: Datos originales sin modificar.
- `data/processed`: Datos limpios y procesados.
- `notebooks`: Cuadernos de análisis y ejercicios (`semana_01_contexto_ambiente.ipynb`).
- `outputs`: Archivos exportados, gráficos y reportes.
- `docs`: Documentación técnica, bitácora y entregables conceptuales.
- `scripts`: Código Python reutilizable.

## Buenas Prácticas
1. No modificar directamente los datos originales en `data/raw`.
2. Documentar cada decisión analítica en los cuadernos.
3. Proteger la privacidad de los datos personales.
4. Usar siempre rutas relativas.
5. Mantener los notebooks ordenados, explicados y comentados.

## Entregables de la Semana 1
- **Mapa Conceptual:** Disponible en `docs/mapa_conceptual.png`.
- **Análisis de Caso y Diagnóstico:** Desarrollado en el cuaderno `notebooks/semana_01_contexto_ambiente.ipynb`.
- **Script de Verificación del Ambiente:** Ejecutado en el cuaderno principal.
